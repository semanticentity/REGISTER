One Instruction at a Time

A run of notes can be described as one starting note and a list of moves. A computer works the same way: it holds one number, changes it a little, and writes it down, over and over.

In this lesson (about 20 minutes, sound on). You will be able to:
  • build a major scale from its pattern of intervals
  • write instructions that hold a note in a register and store it in memory
  • move a whole scale to a new starting note by changing one number
You will use what lessons 1 to 5 taught: addresses, hex, POKE, note numbers, semitones, and the lead voice at $1100.
It keeps playing while you scroll.

Hear it: walking up

Press PLAY. The lead walks up from middle C to the C an octave above, one note on every other step.

The distance between two notes, counted in semitones, is an interval. more From C to D is an interval of 2 semitones, because the black key C♯ sits between them. From E to F is only 1. There is no black key between E and F.

A set of notes in order of pitch, that tunes are built from, is a scale. more The one you hear is the major scale, the "do re mi" scale. It is built from these intervals, in this order: 2, 2, 1, 2, 2, 2, 1. more

Here are those seven intervals. Change one and listen. Then try 2, 1, 2, 2, 1, 2, 2: the same first note, but a darker sound that many sad songs use. Press MAJOR to go back.

Notice what you just changed. Not the notes themselves, only the moves between them. A scale is one starting note and a list of moves.

On a piano your hand does exactly this. It rests on one key. It moves up by the next gap and presses. It only has to keep one thing in mind: where it is right now.

The computer's hand

So far you have typed every note into memory yourself, with POKE. A computer builds a scale the way your hand does. The part of a computer that does the work, by following commands one at a time, is the processor, also called the CPU. more

Each command is an instruction: one small job the processor knows how to do, like "put 60 here" or "add 2 to that". more

The processor holds the number it is working on in a register: a tiny storage slot inside the processor itself, with a name instead of an address. more There are only a few registers, and the processor can use them faster than anything in memory. Memory is the shelf. A register is the hand.

Instructions written as short words, one per line, are assembly language. more Each family of processors has its own. This page uses x366, the assembly language of the MTMC-16, a small teaching computer from Montana State University. One of its registers is called AL, and it holds one byte.

Four instructions are all you need today:

InstructionWhat it does
MOV AL, 60put 60 in AL
MOV [0x1100], ALcopy AL into memory at address 0x1100
ADD AL, 2add 2 to AL
SUB AL, 1take 1 away from AL

MOV is short for move, but it copies: AL still holds its number afterward. Square brackets mean "the memory at this address". And x366 writes hex with 0x in front instead of $, so 0x1100 is the same address as $1100, the lead's step 0.

Here is a program that starts the scale. Press CLEAR LEAD, then press ONE LINE again and again. Watch AL, and watch the lead's boxes fill in.


  

  
Read the program again. Start on 60, store it, move up 2, store, move up 2, store. That is the scale's list of gaps, written as instructions. Each ADD line is one gap. Each store is your finger pressing a key.

  
Now finish it. Type more lines so the program writes all eight notes, every other step from 0x1100 to 0x110E. Then press RUN ALL.

  


  
More than one hand

  
AL is not the only register. x366 also has BL, CL and DL, and they work the same way. Two registers can hold two notes at once. These four lines put middle C in AL, copy it into BL, drop BL two octaves, and store it on the bass's step 0:


MOV AL, 60
MOV BL, AL         ; copy AL into BL
SUB BL, 24         ; two octaves down
MOV [0x1200], BL   ; the bass's step 0

  
Paste them under your program and press RUN ALL. AL keeps its 60 while BL does the bass part.


  
  
Hear it again: move the whole scale

  
In lesson 3 you moved a tune by changing every note, one POKE each. Look at your program now. Only the first line names an actual note. Every other note is worked out from the one before it.

  
So change MOV AL, 60 to MOV AL, 67 and press RUN ALL. The scale now starts on G and it is still a major scale, because the gaps did not change. One number moved eight notes. One of them now lands on a black key, F♯: starting anywhere but C, a major scale needs black keys to keep its gaps.

  

  
This is your hand on the piano again. The first MOV is where the hand starts. The ADD lines are the gaps. The stores are the key presses. A scale is a list of moves from a starting note, and so is this program. The processor plays it one instruction at a time, keeping its place in a register.

  
Every program on this page also runs on the real MTMC-16. Put .MEMORY 16K on the first line, so the computer has memory reaching up to the chip. The bytes land at the same addresses. The MTMC-16 does not play the chip out loud yet, so listen here.


  
  
Check yourself

Now answer these out loud before you open them.

  
What does MOV [0x1104], AL do, and what is in AL afterward?
It copies the number in AL into memory at 0x1104, the lead's step 4. AL still holds the same number, because MOV copies. See "The computer's hand".

  
From E to F is an interval of how many semitones, and why?
1. There is no black key between E and F, so they are one semitone apart. See "Hear it".

  
Why did changing one line move the whole scale?
Only the first line sets a note. Every other note is the one before it plus a gap, so they all follow the first. See "Hear it again".

  
How is a register different from memory?
A register is inside the processor and has a name, like AL. Memory is outside it and is found by address. There are only a few registers, and the processor works on numbers in them. See "The computer's hand".
