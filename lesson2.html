Bits and Patterns

A byte is not one thing. It is eight switches, each on or off. A drum pattern is a row of switches too, so the two fit together.

Eight switches make a byte

Each switch is a bit: 0 or 1. Each position is worth twice the one to its right. Add up the positions that are on, and that is the byte's value. Click the switches.

1286432168421

Why hex

Split the eight bits into two groups of four. Four bits count from 0 to 15, and hex has exactly 16 digits: 0 to 9, then A to F. So every hex digit is exactly four bits, and a byte is always two hex digits. That is why addresses and bytes are written in hex: you can read the bits straight off it.

1000 0000  =  $80  = 128
1111 1111  =  $FF  = 255
0001 0000  =  $10  =  16

A pattern is 16 bits

A bar of 16 steps is 16 switches: on for a hit, off for a rest. Sixteen bits is two bytes, which is four hex digits. Step 0 is the leftmost bit. Click steps, or type four hex digits and press LOAD.

Packed or one byte per step?

LOAD unpacks the 16 bits into 16 bytes, one box per step, because that is how this chip stores a pattern. Packed, a bar would take 2 bytes instead of 16. Old chips often packed, because memory was precious. REGISTER spends the bytes so each step's box can also hold a note or a pitch, and so a beginner can POKE one step without doing bit math. Both are real designs. Choosing between them is a trade-off of space against simplicity.

A byte as a list of choices

Sometimes the bits of a byte are not a number at all. Each one is a yes or no. The filter envelope's FOLLOW byte at $1084 has one bit per voice: which voices open the filter.

To ask "is the lead on the list?", the chip uses AND: keep only the bits that are on in both numbers. The lead is bit 2, worth 4. If FOLLOW AND 4 is not zero, the lead is on the list. OR does the opposite job: it switches a bit on and leaves the others alone.
