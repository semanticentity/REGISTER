A Sound Is a Struct

A pattern is one byte per step. A sound is different: a handful of settings that belong together. Keeping them together, in a fixed order, is the idea behind structs, arrays and pointers.

Four bytes in a fixed order

An envelope shapes a note over time: how fast it rises (attack), how far it falls (decay), the level it holds (sustain), and how long it fades after (release). REGISTER stores those as four bytes in a row, always in the order A, D, S, R. A group of bytes with a fixed layout is a struct. Each part is a field, found by its offset from the start: A is +0, D is +1, S is +2, R is +3.

Five structs in a row is an array

Every voice has an envelope, and the five sit back to back starting at $1060. That is an array of structs. To find any field: start of the array, plus the voice number times the size of one struct, plus the field's offset.

Pick a voice and move a slider. The address it writes is worked out in front of you. Changing the voice changes only the base, the start of that voice's struct. The offsets never change. A variable that holds a base address like that is a pointer.

One voice, many arrays

The envelope is not the whole sound. Volume is an array at $10B0, one byte per voice. Pan is an array at $10B5. Fine tune is an array at $10A3. Each array has a different size of element, but the voice number is the same index into all of them. A voice is one index that lands in many tables.

lead volume     $10B0 + 2       = $10B2
lead pan        $10B5 + 2       = $10B7
lead attack     $1060 + 2 × 4 + 0 = $1068

Names instead of addresses

Working out addresses by hand is slow and easy to get wrong. So REGISTER lets you write a sound with field names, and the voice you load it on supplies the base. This is exactly what a compiler does with a struct in C: you write voice.attack, and it emits "base plus offset".

Press SHOW AS POKES with the lead, then with the bass. Same names, different addresses. The compiler did the base-plus-offset sums.

What you just learned

Struct: related bytes in a fixed layout. Offset: where a field sits inside it. Array: the same struct repeated back to back. Pointer: a base address that picks one of them. Compiling: turning names into addresses. The sequencer's SND button uses this same format, and its sounds move between voices for the same reason.
