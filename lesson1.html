Memory and POKE

A computer's memory is a long row of numbered boxes. Each box holds one small number. A sound chip reads some of those boxes over and over, and plays what it finds.

Boxes with numbers on them

Every box has an address, its number in the row. Every box holds a byte: a whole number from 0 to 255. That is all memory is.

REGISTER is a sound chip that owns the boxes from $1000 to $1FFF. The $ means the number is written in hex, which counts in sixteens. $1000 is 4096 in everyday numbers. Programmers use hex for addresses because the digits line up with how the hardware is wired; lesson 2 shows why.

The kick drum is 16 boxes

A beat here is 16 steps long. The chip gives the kick drum 16 boxes, one per step, from $1000 to $100F. On each step the chip looks at that step's box. If it holds 1, the kick plays. If it holds 0, it stays quiet.

Press PLAY, then click some boxes. Each click writes a byte to memory, and you hear the change on the next loop.

POKE: write a box by its address

Clicking is a shortcut. The real operation is POKE: put this value in the box at this address. BASIC on home computers had the same command in the 1980s, and people used it to make their machines play sound.

POKE $1000, 1    ; step 0: kick on
POKE $1004, 1    ; step 4: kick on
PEEK $1004       ; read it back

Step 4 is $1000 + 4 = $1004. The address of a step is the start of the voice plus the step number. Try the lines below, then write your own.

A second voice, a second set of boxes

The snare lives at $1020 to $102F. Same rule: one box per step, 1 means hit.

What you just learned

memory-mappedthe chip reads ordinary memory, so writing memory is how you control it

That last row is the big idea. There is no special sound command. The program writes memory, and the chip watches memory. Real game consoles worked this way, and so does the MTMC-16 this chip is built for.
