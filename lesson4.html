A Sound Is a Struct

Every note has a shape over time. That shape is four numbers kept in a fixed row, and keeping things in a fixed row is how programs organize what they store.

In this lesson (about 15 minutes, sound on). You will be able to:
  • name the four stages of a note's envelope: attack, decay, sustain, release
  • find any part of a struct from where it starts plus how far in
  • change one part of a sound with one POKE
You will use what lessons 1 to 3 taught: addresses, bytes, POKE, and the melody from lesson 3.

Hear it: same notes, different sound

Press PLAY. It is the melody from lesson 3. Now press PLUCKED, then SLOW SWELL, then MIDDLE. The notes and their pitches never change. What changes is how each note starts and ends.

The character of a sound, what makes a piano and a flute sound different playing the same note, is its timbre, said "TAM-ber". more

A big part of timbre is a note's envelope: how its loudness changes from the moment it starts to the moment it is gone. more Here is the lead's envelope right now. Left to right is time. Up is loud.

Synthesizers describe an envelope in four stages, always in this order:

  • Attack: how long the note takes to rise to full loudness. more
  • Decay: how long it then takes to fall back to a steady level. more
  • Sustain: that steady level, which the note holds before it fades. more
  • Release: how long the note takes to fade to silence at the end. more

Press the buttons again and watch the shape. PLUCKED has no attack and no sustain: it hits at once and dies fast, like a plucked string. SLOW SWELL has a long attack and a long release, so the notes fade in and blur into each other.

Four bytes in a fixed order

In memory, the lead's envelope is four bytes in a row, starting at $1068. They are always in the same order: attack, decay, sustain, release. A group of bytes kept together in a fixed order is a struct, short for structure. more Each named part of it, like attack, is a field. more

The address where a struct starts is its base address. more How far a field is from that start is its offset. more Attack is +0, decay +1, sustain +2 and release +3. So any field's address is the base address plus the field's offset:

attack    $1068 + 0  =  $1068
decay     $1068 + 1  =  $1069
sustain   $1068 + 2  =  $106A
release   $1068 + 3  =  $106B

What each byte means: attack and decay run from 0 to 500 milliseconds, thousandths of a second, as the byte goes from 0 to 255. Sustain is a level, from silent at 0 to full at 255. Release runs from 0 to 1,000 milliseconds. If all four bytes are 0, the chip uses its own default shape.

Move the sliders while the melody plays. Each one writes one field, and the line under it shows the sum.

Try a plucked note that rings much longer, like a harp: still no attack and no sustain, but a long decay.

Hear it again

Listen to the melody and watch the shape at the same time. The four bytes are the four stages, in the order you hear them. The struct's layout follows the note: the first field is the first thing your ear meets.

That is also why a plucked string and a slow swell can come from the same chip. They are the same struct with different numbers in it. Same pitches, same layout, different bytes, different timbre.

Every voice has this same struct. The kick, snare, bass and noise each have their own four bytes somewhere else in memory. Lesson 5 shows where, and why one formula finds them all.

Check yourself

Give the lead a long, slow fade at the end of every note: a release of exactly 200. Do it with one POKE line, no sliders. Work out the address first.

Now answer these out loud before you open them.

Where is the lead's sustain byte?

$106A: the base address $1068 plus sustain's offset, 2. See "Four bytes in a fixed order".

What do attack 255 and release 255 sound like?

The slowest possible swell: about half a second to fade in and a full second to fade out, so the notes smear into each other. See "Hear it: same notes, different sound".

Why keep the four bytes in a fixed order?

So any field can be found with one sum, base address plus offset, without searching. Everything that reads the struct agrees where each field is.

The bass has the same struct, with its base address at $106C. Where is the bass's release?

$106F: $106C + 3. The base changes; release's offset is still 3. Lesson 5 shows why the bass starts there.
